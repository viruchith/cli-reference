# Help Reference

A comprehensive command-line utilities and tools reference guide for macOS and Linux development environments.

## 📋 Contents

This repository contains detailed documentation and examples for:

- **Command-Line Utilities & Tools** - Essential CLI tools like `cheat`, `fd`, `fzf`, `gh`, `jq`, `rclone`, `ripgrep`, and more
- **Development Language Runtimes & Package Managers** - Node.js, Python, `pnpm`, `uv`, and other runtime environments
- **Media & Imaging Processing** - FFmpeg, ImageMagick, WebP tools, and video download utilities
- **Version Control & Repositories** - Git and GitHub CLI reference
- **Network Diagnostics & Transfer** - `curl`, Netcat, and networking tools
- **UNIX Core Utilities & File Management** - Essential tools like `find`, `xargs`, `tar`, and permissions management

## 🚀 Quick Start

The main reference file is [`help.md`](help.md), which contains categorized command examples for each tool.

### Example Categories

Each tool entry includes:
- **Description** - What the tool does and its primary use cases
- **Code Examples** - Real-world command examples with explanations

### Tools Included

- `yt-dlp` - Download videos from YouTube, TikTok, Instagram, and more
- `ffmpeg` / `ffprobe` / `ffplay` - Multimedia processing
- `jq` - JSON processing
- `ripgrep` - Fast file search
- `git` / `gh` - Version control
- `rclone` - Cloud storage sync
- And many more...

## 📝 Usage

Open [`help.md`](help.md) to find command examples for any tool you need. Each entry follows a consistent format with clear descriptions and practical examples.

## 🔍 Finding What You Need

Use your editor's search functionality to quickly find tools:
- Search by tool name (e.g., `yt-dlp`, `ffmpeg`)
- Search by category (e.g., "Media & Imaging")
- Search by use case (e.g., "download", "convert", "sync")
